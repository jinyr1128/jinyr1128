## About me

안녕하세요. 백엔드 개발 경험이 있는 PM 진유록입니다.

Java와 Spring으로 서비스를 만들며 익힌 구조적 사고를 운영에 적용하고 있습니다. 수강생·강사·멘토·운영팀·기업 담당자의 요구를 정리하고 과정의 목표와 일정, 역할, 지표, 대응 기준을 하나의 운영 체계로 연결합니다.

운영 중 발생한 문제를 개인의 경험에만 맡기지 않습니다. 출결·과제·상담·만족도 데이터를 확인하고 반복되는 이슈는 체크리스트와 문서, 협업 규칙, 제품 요구사항으로 구체화합니다. 교육 현장을 이해하는 PM이면서 개발팀과 기능 요구사항을 논의할 수 있는 사람으로 계속 성장하고 있습니다.

> 느리더라도 매일 한 걸음씩. 배우고 기록하고 더 나은 방식으로 바꿉니다.

## Core strengths

### 1. 데이터를 행동으로 바꾸는 운영

지표를 보고서에 남기는 데서 끝내지 않습니다. 출결, 과제 제출, 질문 감소, 팀 갈등 같은 신호를 조기에 확인하고 상담, 학습계획 조정, 강사진 협의, 후속 확인으로 연결합니다. 과정 종료 후에는 수료율·만족도·이탈 사유를 함께 회고해 다음 차수의 운영안에 반영합니다.

### 2. 여러 이해관계자가 함께 움직이는 구조 설계

수강생, 강사, 멘토, 운영팀, 기업 담당자는 같은 문제를 서로 다른 관점에서 봅니다. 각자의 요구를 역할·기한·산출물·판단 기준으로 바꾸고 일정 변경이나 고위험 이슈가 생기면 영향 범위와 우선순위를 다시 조정합니다.

### 3. 개발과 운영을 연결하는 문제 해결

개발 경험을 살려 현장의 불편을 기능 요구사항으로 구체화합니다. 사용자, 상황, 필요한 기능, 완료 기준을 정리해 개발팀과 논의하고 수기로 반복되는 업무는 데이터 수집 방식과 대시보드, 알림 기능으로 개선합니다.

### 4. 팀 운영의 공백을 줄이는 리더십

팀 리더 역할을 맡아 팀원의 연차와 교육 일정, 업무량을 함께 확인하고 과정별 필수 업무의 담당자와 대체 인력을 조정합니다. 일정 충돌이나 긴급 이슈가 생기면 영향 범위를 확인해 우선순위와 기한을 다시 정합니다. 운영회의와 개별 피드백으로 판단 기준을 맞추고 체크리스트와 이관 경로를 남겨 특정 담당자의 경험에만 의존하지 않도록 합니다.
